# Mordhau harness 1: helm previews

Each picture is one helm worn on a grey head and shoulders, in bright steel, seen (left to right) from the **front**,
the **side**, the **back** and three-quarter front. `_visor_up` is the same helm with its visor raised (the visor key).
Drawn with `tools/bbmodel_preview.py` from the baked models, the way the game draws them; not screenshots from the game.
