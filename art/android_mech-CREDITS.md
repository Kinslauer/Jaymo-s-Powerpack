# Android mech asset credit

The android mech's geometry, box UVs and four 128×128 skins are existing **original Jaymo's Powers art**, generated by `tools/gen_android_mech.py` from the project's own design. No external model, texture or animation data was used.

The shared skeleton, build-filtered editable projects, original animation keyframes and GeckoLib conversion are by **Prometheus (hermes-modeller)** for Jaymo's Powerpack, using `tools/gen_android_mech_gecko.py`.

## Asset notes

- `android_mech.bbmodel` is the editable shared 33-bone/33-cube rig; `android_mech_<build>.bbmodel` retains each build's original optional parts and skin.
- `idle`, `walk`, `smash`, `cannon`, `shell`, `hurt` and `death` are used by the game; `aim` is a reference pose for old/new render comparisons. Cannon pitch/yaw and head look remain render-time adjustments.
- The walk reproduces the old leg, knee, arm and torso motion. Smash retains the ten-tick double-arm lift. Cannon recoil is below the shoulder so aiming is not disturbed.
- No powering-up/down animation is wired because the mech has no such gameplay state.
- `android_mech-render.png` combines exact front/right/back/left `tools/mesh_to_cubes/bbrender.py` inspections of all four builds. Every cuboid has six textured faces and every used UV rectangle was checked opaque.
- `android_mech-walk-comparison.png`, `-aim-comparison.png` and `-smash-comparison.png` compare the old Java poses with the new keyframes. Walk and aim produced identical model extents.
- `android_mech-animations.png` inspects idle, recoil, shell, hurt and death poses from five angles.
- GeckoLib itself is an external MIT-licensed dependency (Tslat and contributors); no GeckoLib code or art is included in these assets.
