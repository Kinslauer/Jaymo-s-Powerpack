Modrinth project iMWTKEcK, file "1.21.1 Nordic Structure 1.1.3" (Nordic_Structure-1.1.3.jar, Fabric 1.21.1)
The jar declares "license": "MIT" (fabric.mod.json, author listed there: bulochka_s_tiltom); the Modrinth page adds
"Feel free to use it in any modpacks". The jar ships no licence text, so the standard MIT text follows.

Used in Jaymo's Kingdoms: the eleven tomb templates (data/jaymoskingdoms/structure/stormborn_tomb/), changed so that
everything from Supplementaries, Draugr Invasion, DungeonZ, FrogiLib and Moonlight Lib is replaced with vanilla or
Kingdoms content, and the chest loot tables (data/jaymoskingdoms/loot_table/chests/stormborn_tomb_*), with the same
swaps. The descent template and the StormbornTomb structure type are Kingdoms' own.
