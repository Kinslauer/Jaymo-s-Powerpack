# Atroxiia asset credit

Atroxiia's geometry, 256×256 UV layout, hides, marking sheets and original motion design are **Jaymo's Kingdoms project art**, generated by `tools/gen_atroxiia.py` and the former `AtroxiiaDragonModel`. No external model, texture or animation data is included.

The editable Blockbench conversion and sampled GeckoLib keyframes are by **Prometheus (hermes-modeller)** using `kingdoms/tools/gen_atroxiia_geo.py`.

Saint's Dragons by Leon Saint is a **motion/gameplay reference only**. Its code is MIT, but its art is All Rights Reserved; no Saint's Dragons art, models, texture pixels, sounds or extracted keyframes were copied. All keyframes here are sampled from our own pre-existing Java pose equations.

## Asset notes

- `atroxiia.bbmodel` contains 61 uniquely named bones, 61 fully textured cubes and 19 animations.
- States: idle plus taunt/sniff/grumble fidgets, walk, run, sit, crash and swim. Atroxiia is not a flier, so no fly/glide/land animations exist.
- Server actions: slam, swipe, precise strike, Gungnir, devastating sweep, Helheim quake, bite, tail lash, hurt and held death.
- Existing hide/marking selection, headdress variants, brow crystal, spine visibility, saddle/strap/pad, 1.15 draw scale, 0.35 hatchling factor, seats and culling reach are unchanged.
- `atroxiia-render.png` is the exact front/right/back/left `tools/mesh_to_cubes/bbrender.py` inspection with optional look/tack pieces deliberately hidden.
- `atroxiia-comparisons.png` contains all 19 old-Java/new-GeckoLib pose comparisons, five views each. The full sheet and close-up sit/crash, Gungnir/sweep and lash/hurt/death regions were visually inspected.
- GeckoLib is an external MIT-licensed library (Tslat and contributors); no library code or art is included in these assets.
