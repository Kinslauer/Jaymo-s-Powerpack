# The orders' sets show

These apply only where Fantasy Armor is loaded.
- Anyone wearing the whole of an order's set gives off a faint mote now and then, in the set's colour. A set with a worn-out piece gives none. This covers the dawnwatch, the headsmen, the sky elders, the well-wardens, the ashen plate, the hunters, the barrow wardens, the Giant-slayers, the pit and the twinned.
- People notice a player in one of those sets and say so in one oblique line. Each person says it at most once a day. Goblins and orcs have their own lines.
- Fantasy Armor's own capes already hang from its sets, so we add none.
- Built; not played.
