# Night's Blood 4 — the true shape of the night

- Adds the gaunt winged horror model, texture and animations for the vampire player's fifth shape.
- Includes GeckoLib model `night_horror.geo.json` and animations `idle`, `walk`, `run`, `leap`, `strike`, `roar`.
- Five vampire skin palette-swaps: ashen (default), pale, dusk, russet and ebon, plus an emissive eye/maw glow layer.
- Art is original vanilla-style pixel work; the editable `kingdoms/art/night_horror.bbmodel` and the `kingdoms/tools/gen_night_horror.py` generator are kept alongside the exported assets.
- Not tested in game (models and animations only; the corresponding entity/ability code is in the Night's Blood 4 code task).
