# Youth says "be right back" on a long answer
- When an answer takes so long that the wood-wisp would fade (2 minutes), it first tells the asker a "be right back"
  line ("Studying that! Back soon.", "Off to ask the elders. Back soon!", six in all), then the answer brings it back.
  `/youth summon` marks the question as waiting; `/youth say` answers it. A wisp called with no question fades quietly.
