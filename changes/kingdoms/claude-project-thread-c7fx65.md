# journal map tab opens Xaero's World Map
- **Map tab**: with Xaero's World Map installed, the traveller's journal's Map tab opens Xaero's full map (where you are,
  what you've explored, its waypoints) instead of our drawn map. Escape or Xaero's map key closes it back into the journal.
  Without Xaero's World Map (or while its map is still loading as you join), the journal's own map shows as before.
  Xaero's Minimap alone has no full map, so the journal keeps ours then.
- XaeroJournalMap (new, loaded only when `xaeroworldmap` is), JournalScreen. Compiled against Xaero's World Map
  1.47.2 (compileOnly), never required.
- Built; not played.
