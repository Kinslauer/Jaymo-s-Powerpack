# Rain barrels beside village houses
When Jaymo's Kitchen is installed, a village's builders set a rain barrel against the east wall of each house they put up, on a footing of the house's own foundation stone. The house plan grows by one block on that side, so the crew levels and clears it with the rest. It is wood, so the crew pays for it as for a plank, and it starts empty and fills in the rain. A house with no plain wall for it goes without. Without Kitchen nothing changes.
- Class: `RainBarrels`, hooked in `Blueprint#register` beside the trade signs.
- Built; not played.
