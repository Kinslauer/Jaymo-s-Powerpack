# Werewolves can eat any body with flesh on it
- For Jaymo's Kingdoms' werewolves: `CorpseEntity.isFleshForDevourer` (any body lying still that isn't a player's, the risen dead's, iron, burning, carried or carted) and `Scavengers.devourable/devourBite` (a scavenger's bite, torn open after the number of bites the eater asks for). The scavengers' tearing is the same code (`Scavengers.tear`).
- Built; not played.
