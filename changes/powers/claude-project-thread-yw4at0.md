# Alex's Mobs Continued joins the pack
- **Alex's Mobs Continued** 2.3.0 (Codx.io's Fabric 26.3 port, LGPL-3.0 in its jar, shipped unchanged; needs CodxLib, already in the pack) joins `packMods`: seagulls, orcas, cachalot whales, giant squid, seals, frilled sharks, blobfish, comb jellies, mimic octopuses, lobsters and the rest of its animals. Andy wanted all of them, so its animals that match Naturalist's, Cube Animals' or ours spawn alongside them as other breeds.
- Its mod id `alexsmobs` leaves `removedIdsFromProfile`, so Build Modpack no longer moves it out. Citadel and the old port's jars still go.
- The old port (0.8.82) left in 0.8.107 because its models drew black slabs and streaks with Iris shaders. This is a different port, but worth a look with shaders on.
- Not played.
