# Fancy World Animations 1.3.7: the game starts again
- Fancy World Animations 1.3.0 patched a part of Entity Culling that version 1.12 (added with the Sensible MC picks) no longer has, and the game stopped while loading. The pack now carries 1.3.7, made for it.
- Pull requests that change the pack's mods are now checked for mods whose declared needs (Fabric Loader, Minecraft, other mods' versions) the pack doesn't meet, the kind that stopped the server this morning.
