# Armor remade in vanilla style

- **Armor textures**: the mod's two player armor sets — bog_iron and caveman (helmet, chestplate, leggings, boots each) — remade in pure vanilla Minecraft style: solid 1-pixel outlines, flat solid colors per section, crisp 16x16 pixel art, no gradients or anti-aliasing. Iron-gray for bog_iron, hide-brown for caveman, matching each set's existing palette.
- PNGs only: no model JSON, item model, or Java changes.
- Note: the task text also names tiered leather/iron/gold/diamond/netherite armors under textures/item/armory/, but the mod registers no such armors — only bog_iron and caveman exist, so those are the textures remade.

Built with `sh ./gradlew build`; not played in game.
