# explorer maps never make chunks on the server thread
- **Fix**: the Deck crashed (watchdog, 60 s) when a downed wandering trader was finished off: Droppable Villager Trades made its offers on death, one was an explorer map, and vanilla's structure search made chunks on the server thread. Every explorer map (cartographer and wandering trader trades, shipwreck and ocean ruin chest maps) now finds its structure with Scout on the server thread, over the same search radius, with no chunk made. Alex's Caves' underground cabin maps (added to many chests by its own loot modifier) are routed the same way. Off the server thread vanilla's search runs as before.
- **Differs from vanilla**: Scout trusts the prediction instead of loading the chunk to confirm, and can't add a reference (that needs the chunk). Maps that skip known structures still leave out starts the structure cache or saved chunks show as already claimed, but a start not made yet can't be told claimed, so two maps may point at the same structure. In a One Dimension world it searches the Overworld band, and concentric-ring placements (strongholds) are not searched.
- `ExplorationMapScoutMixin`, `CabinMapScoutMixin` (a `@Pseudo` mixin in the Alex's Caves config, so the game loads without it), `Scout`. Not built locally; CI builds it. Not played.
