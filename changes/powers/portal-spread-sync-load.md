# Nether Portal Spread no longer freezes the server in land not yet ready
- **Fix**: the server no longer crashes (watchdog kill) when Nether Portal Spread checks a portal in land that is still loading or generating, for example after a player teleports far outside the pre-generated area. A new portal waits at the end of the mod's queue until all the land round it is ready, and a known portal skips its spreading round until then (as the mod already did for a portal in unloaded land), so it is never mistaken for broken. Nether Portal Spread behaves as before everywhere else, and nothing changes if the mod is absent.
- Classes: `PortalSpreadQueueMixin`, `PortalSpreadLookMixin` (`mixin/portalspread/`, config `jaymospowers.portalspread.mixins.json`), `compat/PortalSpreadCompat`.
- Built by CI; not played.
