# tool stations mark the maker for class experience
- Building gear at a tool station puts a short-lived tag on the player (`Tinkering.MADE_TAG`); Jaymo's Kingdoms reads it, takes it off and gives the Tinkerer class XP.
- Three hooks for Jaymo's Kingdoms' class trees, all doing nothing without it: `LockOnRegions.sure` (an aimed head shot that can't miss or glance), `Downed.headKnock` (how likely a thrown rock or blunt arrow to the head knocks someone out) and `Bleeding.closing` (how soon someone's wounds close by themselves).
- Built; not played.
