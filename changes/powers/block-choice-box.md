# block-choice-box (0.20.18)

This PR adds a choice box that appears when sneaking + right-clicking a liftable block (not in
`#jaymospowers:carry_on_no_lift`) with empty main hand. The box offers:

- **Use (...)**: performs the block's normal sneak-use action. The label indicates the action
  (e.g. `Use (bake)` for furnace, `Use (cook)` for campfire, `Use (chop)` for cutting board).
- **Lift**: Carry On lifts the block with its contents.
- **Open door** (CfB oven only): the oven's own sneak-click (its door), skipping Kitchen's station handler.

The blocks removed from the no-lift tag in this PR are: campfires, furnace, smoker, blast furnace,
Cooking for Blockheads' ovens, counters, cooking tables, cutting board, Kitchen's stove, cutting board,
cooking pot, frying pan, spits, hearth, brewing keg, cask, still, tea kettle and sushi mat. The original
no-lift entries (pod parts, salvage rack, smeltery, kiln load, sentry spawner, infusion matrix, Kingdoms'
bounty board, pulley, plot stake, windmill, waterwheel) remain.
