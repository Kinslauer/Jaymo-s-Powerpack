The effects were saved as runtime containers with the Effekseer editor. Dependency paths keep the original directory structure and use lowercase names for Minecraft resource lookup. Textures and models are the contributors' original files.

The Fabric client renderer and resource loader are adapted from [AAA Particles by ChloePrime](https://github.com/ChloePrime/AAAParticles/tree/94d3cb8cbae9293dd2b974042ddf04c3ca0402be). Powers includes its generated JNI bindings and the OpenGL natives from that revision. See [AAA Particles' MIT license](AAA-Particles-MIT.txt) and [Effekseer's MIT license](Effekseer-MIT.txt).
