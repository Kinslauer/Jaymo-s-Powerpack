# Split view — see every thread at once

Obsidian opens notes in the current pane by default. To view multiple threads side by side:

| What you want | How to do it |
|-------------|--------------|
| **Two notes side by side** | Hold `Ctrl` (or `Cmd` on Mac) and click a note in the file explorer, or right-click a note → **"Open in new split"** |
| **Three+ notes at once** | Repeat: open each additional note in a new split; drag the divider to resize panes |
| **Same note in two panes** | Open it once, then "Open in new split" again — edits sync across both |
| **Close one pane** | Click the `×` on that pane's tab; the note stays open in the others |

## Recommended layout for this vault

Keep three panes open:

1. **Left pane:** `Agents.md` — who's working on what, claim status
2. **Middle pane:** `Context.md` — build rules, versions, standing rulings
3. **Right pane:** the active project note under `Projects/` — the thread you're in right now

When a PR merges, close its project pane and open the next one.

## Quick reference

| Action | Windows/Linux | macOS |
|--------|-------------|-------|
| Open file in new split | `Ctrl` + click file | `Cmd` + click file |
| Move focus between panes | `Ctrl` + `1` / `2` / `3` | `Cmd` + `1` / `2` / `3` |
| Close active pane | `Ctrl` + `W` | `Cmd` + `W` |
