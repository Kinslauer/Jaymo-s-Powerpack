# Fable second opinions

Free, manual second opinions on bot PRs and modding questions, using Fable 5.2 in DeepAI Code. The bots can't use it, since there's no API.

**Sign up:** free account at [deepai.org/chat/ai-code](https://deepai.org/chat/ai-code), then pick Fable 5.2. Free accounts get 250 "Theos" a day.

> [!warning] Keep secrets out
> It's a third-party site. Never paste keys, `.env` contents or private vault notes into it.

## Second opinion on a PR

"You're reviewing a pull request for a Fabric 26.3 Minecraft mod (Jaymo's Powers). List real bugs only, most serious first: crashes, broken logic, server/client mixups, missing registrations. Skip style nitpicks. End with: safe to merge, or not yet and why. Diff below:"

Then paste the diff. You can get it by adding `.diff` to the end of any PR link on GitHub (for example `https://github.com/Kinslauer/Jaymo-s-Powerpack/pull/1568.diff`).

## Modding question

"I'm building a Fabric 26.3 mod with mojmap names. Answer briefly, show code if needed, and say if you're unsure whether an API exists in 26.3."

## Note

Fable can be wrong about brand-new Minecraft versions, so treat its answers as a second opinion, not the final word. Merges still wait on Andy's word.
