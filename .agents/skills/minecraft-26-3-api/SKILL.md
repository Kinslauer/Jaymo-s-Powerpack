# Minecraft 26.3 APIs

Check every Minecraft API against the 26.3 sources before using it: run `./gradlew genSources` and read the real
signature. Don't trust memory of older versions.

The facts that keep catching agents out are written down: `docs/HANDOFF.md` ("26.3 API facts learned the hard way")
and `docs/AI-HANDBOOK.md` ("26.3 facts that keep coming up"). Read both before guessing.
