# Building library downloads

The world-only rows of Andy's medieval schematics picks (2026-11-19; plan: `docs/BuildingLibrary-Plan.md`). Their sites give
no licence to hand the files on, so they are never put in git or in the mod: each world keeps its own copies.

**How:** download each file below (the sites show ad pages before the download, and they block the cloud, so this is done
by hand) into `C:\Users\toopo\Downloads\building-library\`, saved under the name in the **Save as** column (keep the
file's own extension: .litematic, .schem or .nbt). The PC reviewer copies the folder into the server world's
`jaymoskingdoms_library/` folder with the next pbdr; then `/kingdom library reload` (or a restart) reads them.

Named like this, each file is sorted by itself (its kind and land are in `kingdoms/src/main/resources/jaymoskingdoms/library.json`,
under `world`). Any other file still shows on the mason's table as an unsorted pattern book; `/kingdom library tag "<file>" <kind> [land]`
sorts it for the builders (`/kingdom library list` shows what each file became). Old `.schematic` and Bedrock `.mcstructure`
files can't be read: the server log names them.
