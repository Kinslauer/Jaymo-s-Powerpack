# Codemap

One line per class (path, what it does, main methods), made by `tools/codemap.py`. **Grep these before searching the
code**, then open only what you need. Regenerate with `python3 tools/codemap.py` after adding classes (do it at the
end, right before the PR: it's a shared file).
