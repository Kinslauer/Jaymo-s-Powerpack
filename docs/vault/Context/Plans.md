# Plans and specs

Designs and Andy's answers live in `docs/*-Plan.md` and `docs/*-Spec.md` (about 60 files). Grep for the feature
name; the [GitHub docs folder](https://github.com/Kinslauer/Jaymo-s-Powerpack/tree/master/docs) lists them all.

- `docs/Plan-0.8.md`: the 0.8 playtest patch in four tracks (Gravity, Arsenal, Chrono, Web). **Built and merged**;
  still the best example of splitting one patch into parallel tracks that don't share files, with the open questions
  for Andy collected at the end.
- `docs/Abilities.md`: the table of every ability. Andy edits its "Change to" column to request changes.
- `docs/Kingdoms-Plan.md`: Kingdoms' plan and Andy's answers.
- `docs/<power>.md`: per-power design notes.
- `docs/HUD-Layout.md`: where HUD pieces go (bottom-right, `HudZones`/`HudStyle`).
- `docs/AGENT_BRIEF*.md`: older briefs handed to agent tracks; a model for writing a new one.
